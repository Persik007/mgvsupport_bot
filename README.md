<h4>Задача 1 - Telegram эхо-бот</h4>

Создать телеграмм бот, который будет возвращать текст, который отправил пользователь

Как работает бот:
<ul>
    <li> <code>/start</code> бот рассказывает что он умеет и как с ним работать</li>
    <li> <code>/help</code> показывает справку, что бот написал при /start</li>
</ul>

Пример диалога:
````
П: /start
B: Привет, я эхо-бот. Я повторяю все, что вы напишите. Напишите, любое сообщение. Команда /help покажет эту справку еще раз
П: привет
B: Вы набрали привет
````

<h4>Задача 2 - Бот поддержки: управление обращениями(CRUD)</h4>
Пользователь создает, просматривает, редактирует и удаляет свои обращения в поддержку

<ul>
    <li><code>/new</code> - бот спрашивает тему и описание, далее сохраняет обращение с номером</li>
    <li><code>/list</code> и <code>/ticket N</code> - просмотр тикетов или конкретного тикета, где N - натуральное число, номер тикета</li>
    <li><code>/edit N</code> - изменить описание тикета</li>
    <li><code>/delete N</code> - удалить тикет</li>
</ul>

Пример диалога:
````
П: /help
Б: Команды:
/new - создать обращение
/list - мои обращения
/ticket N(номер тикета) - показать обращения с номером N
/edit N - изменить описание обращения с номером N
/delete N - удалить обращения с номер N
П: /new
Б: Опишите проблему
П: Списали деньги
Б: Обращение N1 создано

П: /list
Б: Ваши обращения:
№1 Списали деньги, подписка не пришла
№2 Не работает на телефоне
П: /edit 1
Б: Введите новое описание обращения №1
П: Списали 189₽, подписка не активировалась
Б: Обращение №1 обновлено

П: /delete 2
Б: Обращение №2 удалено
П: /ticket 2
Б: Обращения №2 не найдено
П: /ticket 7
Б: Обращение №7 не найдено
````
Как запустить:
1. Получите token у @BotFather
2. Скопируйте .env.example в .env и впишите туда свой токен и имя бота
   BOT_TOKEN=ваш_токен
   BOT_NAME=имя_бота
3. Соберите проект
   mvn clean package
4. Запустите бота
   java -jar target/mgvsupport-1.0.jar
